Fonts used to draw the gift coupon ticket pictures for email
(src/modules/user/gifts/ticketImage.js).

- Inter (Regular, SemiBold, Bold, ExtraBold) — the site's text font. Has the ₹ sign.
- Courier Prime Bold — for the coupon code (the site shows it in Courier New).

Both are from Google Fonts under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with software.
